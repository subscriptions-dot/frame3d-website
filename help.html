Help & install

Get started.

Download Frame3D, install it on your Quest in about ten minutes, and start exploring. Fixes for common problems are below.

InstallFix a problemReport a bug

Install on your Quest

Download for Meta Quest ↓

Frame3D-quest.apk · always the newest version · release notes and all files

The GitHub version is installed from a computer (sideloading). You need the headset, a computer and a USB-C cable. You only do the setup once.

  1. Turn on developer mode. In the Meta Horizon app on your phone, open your headset's settings and switch on Developer Mode.
  2. Connect the headset. Plug the Quest into your computer with a USB-C cable, put it on and allow USB debugging.
  3. Download the app. From the latest release, download Frame3D-quest.apk (the button above).
  4. Install it. Open SideQuest on the computer and drag the file onto its window. (If you use the command line: adb install -r Frame3D-quest.apk.)
  5. Open Frame3D. In the headset, open the Library and look under Unknown Sources.

Later updates: the app checks GitHub and offers new versions itself.

Fix a problem

A photo or video does not turn 3D

Press the 3D button on that photo or video. Protected (DRM) video cannot be converted. If it still stays flat, close and reopen the tab, then send a report (below).

A VR video plays flat

Choose the video's layout (180°, 360° or side-by-side) so it matches how it was filmed.

An add-on does not work

Some add-ons depend on desktop-only features. Turn it off and on again in the add-ons list, or try another add-on that does the same job.

The app feels slow

Close tabs you are not using and keep fewer windows open. If a page is heavy, turning its 3D off makes it lighter.

Something else

Send a report (below) and say what you were doing when it happened.

Report a bug

  1. In Frame3D, open Settings and press Export diagnostic summary. It is saved on your headset and leaves out web addresses, history and cookies.
  2. Open an issue on the Frame3D releases page, say what happened and attach the summary if you want to.
