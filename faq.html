FAQ.

Short answers to what people ask most.

What is Frame3D?

A web browser for Meta Quest that turns the photos and videos on web pages into 3D while you browse. The depth is worked out on the headset itself.

Which headsets does it run on?

Meta Quest headsets. placeholder Add the exact list of supported models here.

Is it free?

Yes, the version on GitHub is free to download. Get the latest release.

Do I need an account?

No. There is no Frame3D account, no cloud sync and no analytics.

Are my pages or photos sent anywhere to make the 3D?

No. The depth maps are made on the headset's own GPU. Pictures and video frames are not uploaded for it.

Can I watch 180°, 360° and side-by-side video?

Yes. VR video plays the way it was filmed: 180° and 360° wrap around you, and side-by-side 3D shows each eye its own half.

Can protected video (Netflix and similar) be turned into 3D?

Protected (DRM) video plays as normal, but it cannot be converted to 3D, because the browser is not allowed to read its frames.

Do my Firefox add-ons work?

Frame3D installs real add-ons and themes from addons.mozilla.org. Add-ons that depend on desktop-only features may not work in the headset.

How do updates work?

The version installed from GitHub checks GitHub for a newer release and offers it. Store versions are updated by Meta.
